## 五、关于「停止运行」按钮（已恢复并加固）

先说结论：**按钮在 HTML 和逻辑里一直没有被删**（`index.html` 里 `#btn-stop` 与 `app.js` 的 `setRunningUI/stopRun` 都在），我上一轮交付的截图里看不到它，是因为那几张图用注入的假 run 渲染，没走 `pollRun()` 这条会更新按钮显隐的路径——看起来就像被删了，抱歉误导。

这一轮做了三件事：

1. **外观升级**：`■` 文字符号换成内联 SVG 停止图标，红色描边（`.btn.stop`），在「清空 / 开始运行」中一眼可辨。
2. **状态同步加固**：新增 `syncRunControls(run)`，把「是否显示停止按钮」的判定从只存在于 `pollRun()` 收敛到 `renderRun()` 内部调用。这样轮询、人工审核、点击停止、点历史记录等**任何**渲染路径都会同步按钮，不会再出现「任务在跑却没有停止入口」。
3. **停止中反馈**：点击后按钮变为「⟳ 停止中…」（红色 spinner）+ 置灰不可重复点击，直到后端确认；失败会恢复并弹提示。

显示条件：当前运行状态属于 `running / waiting_review / queued / cancelling` 时出现。截图见 `01_左栏与停止按钮.png`、`07_停止按钮_运行中.png`。
